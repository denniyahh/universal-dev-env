<objective>
Implement the deletion lifecycle (SYNC-01, D-12..D-16, D-14): classify deletions explicitly, propagate upstream deletions on pull and local deletions on push, never turn an absent file into an empty one, and stop resurrection with tombstones.

Purpose: today an upstream deletion is classified UpstreamModified and pull fails reading the missing file; a local deletion fails push's mandatory read; and a both-sides deletion can come back as a 0-byte file (remediation plan 1.1). ROADMAP success criterion 1: an upstream deletion propagates on pull and does not resurrect on later pushes.

Output: new SyncStatus variants and truth table, Tombstone records, stage_delete in the transaction, deletion handling in pull and push, name-status publication gate, CLI rendering.
</objective>

PHASE SYNC STATE TABLE (authoritative for plans 01-07, 01-09 and 01-10; those plans cite it instead of restating it). Research Pattern 3, extended at revision 2026-10-18 with the tombstone and conflict-record columns so every combination the phase's flows can create has exactly one status and one pull / push / resolve outcome.
Notation: A = files record with ancestor fingerprint; T = tombstone; C = open conflict record (plan 01-09); L / U = local / upstream fingerprint; `absent` = no file (None, never the empty string; an empty file is present).
Invariants: (I1) a path never holds both a files record and a tombstone: `ProjectState::record_file` clears the path's tombstone (this plan, Task 1), so every recording path (pull write, pull InSync reconcile, push persist, resolve) clears it. (I2) a `.local` override changes only rows where the local file is present, exactly as today's compare_3way_hashes rules; deletion rows and the Absent row ignore it.
Precedence: (P1) C open and NOT converged -> ConflictPending, overriding every C-less row (this is how D-08 "each conflicted file is left untouched" and D-09 "resolved with an explicit command" apply to deletion rows). Converged := L and U both present with equal fingerprints, or L and U both absent. (P2) C open and converged -> the status of the matching C-less row, and pull additionally clears C (convergence, D-09 amendment). (P3) no C -> the C-less rows.
