<objective>
Make direct push verify branch continuity and abort cleanly when upstream moved after UDE fetched it (SYNC-06, D-18): publish nothing, undo the local cache commit, exit 1, never force-push.

Purpose: today a rejected push is just "git push origin main failed" (exit 1, same as any failure), the cache keeps an orphan commit, and nothing distinguishes a race from a broken remote. ROADMAP success criterion 6: outbound push verifies branch continuity and rejects divergent push candidates safely.

Output: fetched-head tracking, continuity check, porcelain push with rejection classification, typed push error, CLI exit mapping, unit and e2e tests.
</objective>
