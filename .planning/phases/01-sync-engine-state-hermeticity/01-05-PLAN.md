<objective>
Stop false drift from line endings (SYNC-04): hash over LF-normalized text, classify by fingerprint instead of raw string equality, migrate existing state files to the new hash semantics with a version bump (D-07), and preserve each file's line-ending style when UDE writes it.

Purpose: research Pitfall 1 found that fixing the hash alone does not help, because scan_project compares raw strings when all three contents are present. This plan moves classification to fingerprints and keeps merge as the only content-level operation.

Output: fingerprint / EOL helpers, fingerprint-based classification, schema version 2 with migration, EOL-preserving writes in pull and push, unit and e2e tests.
</objective>
