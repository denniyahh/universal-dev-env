<objective>
Make multi-file materialization transactional (SYNC-02, D-05): stage and validate every write before touching any target, then rename, with state.json committed last; set file modes explicitly; and route push's template writes through the same path.

Deletions (plan 01-07) and conflict sidecars (plan 01-09) plug into the transaction built here.

Output: new module src/sync/staging.rs, pull and push write paths rewritten on top of it, tests for fault injection, modes and symlink refusal.
</objective>
